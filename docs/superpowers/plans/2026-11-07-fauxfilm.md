# Faux Film Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS app that frames iPhone photos as true-size instant-film prints (Instax Mini/Square/Wide, Polaroid square) and prints them on US Letter sheets with crop marks for hand cutting.

**Architecture:** All logic lives in a local Swift package `FauxFilmKit`: formats, layout math, crop, image decode, looks, rendering, pagination, PDF and the `Session` model. It is fully unit-tested with `swift test`. A thin SwiftUI app target (`FauxFilm`), generated by XcodeGen from `project.yml`, provides the window, the Photos picker, cropping gestures, the sheet preview and printing. Printing always goes through a PDF that the app builds itself, at exact physical size.

**Tech Stack:** Swift 6, SwiftUI, Observation, Core Graphics, Core Image, ImageIO, PDFKit, PhotosUI, AppKit printing; XcodeGen; XCTest/Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-07-fauxfilm-design.md`

## Global Constraints

- macOS 15.0 deployment target; Swift 6 language mode; no third-party runtime dependencies.
- All physical geometry in **millimetres**, top-left origin, y down. Convert to PDF points only at draw time: `pt = mm * 72 / 25.4`.
- Paper: US Letter **215.9 × 279.4 mm** portrait. Gap **4 mm**. Safe margin **6 mm**.
- **Never scale a print to fit.** No fit-to-page anywhere.
- Border colour `#F6F4EE`, one constant. Film look default **None**.
- Photos embedded at **300 dpi** at printed size.
- Crop marks: hairline (0.25 pt), offset **1 mm** from prints, **3 mm** long in margins, never touching a print. No continuous cut lines.
- App sandboxed: `com.apple.security.app-sandbox`, `com.apple.security.print`, `com.apple.security.files.user-selected.read-write`. Sign to Run Locally.

## Review Focus

1. **iPhone portrait photos carry EXIF rotation.** They must appear upright, not sideways (Task 3 test).
2. **48 MP HEIC originals.** Import must downsample (≤4096 px long edge) so memory and render time stay sane (Task 3 test).
3. **Printer can't print as close to the edge as the layout needs.** Warn and offer fewer rows, never shrink (Task 2 `isInside` tests + Task 8 flow).
4. **Panoramas and screenshots with extreme aspect ratios.** At zoom 1 the crop still fills the window with no empty space, and panning clamps (Task 3 test).
5. **PNG/screenshot with transparency.** The picture window prints opaque, not see-through to the paper (Task 4 test).

### Task 2: Sheet layout and crop marks

**Files:** `Sources/FauxFilmKit/SheetLayout.swift`, `Tests/FauxFilmKitTests/SheetLayoutTests.swift`

**Interfaces — Consumes:** `FilmFormat`, `Paper`. **Produces:**
- `public struct Slot: Equatable, Sendable { rect: CGRect /* sheet mm, card footprint */; rotated: Bool /* card turned 90° clockwise */ }`
- `public struct Tick: Equatable, Sendable { from: CGPoint; to: CGPoint }` (mm)
- `public struct SheetLayout: Sendable { format; paper; columns; rows; slots: [Slot] /* row-major */; ticks: [Tick]; static func make(format:paper: = .letter, gap: Double = 4, margin: Double = 6, maxRows: Int? = nil) -> SheetLayout; func isInside(_ imageable: CGRect) -> Bool /* every slot rect inside imageable (mm) */ }`

Algorithm: for both orientations (unrotated, rotated), `cols = floor((W − 2m + g)/(w + g))`, `rows = min(maxRows ?? ∞, floor((H − 2m + g)/(h + g)))`. Pick more slots; a tie goes to unrotated. Centre the grid on the paper. Ticks, with o = 1, L = 3:
- In every **row gap**, at each column's left and right edge x: a vertical tick from `rowBottom + o` to `nextRowTop − o`.
- In every **column gap**, at each row's top and bottom y: a horizontal tick from `colRight + o` to `nextColLeft − o`.
- In the **side margins**, at each row's top and bottom y: horizontal ticks `[gridLeft − o − L, gridLeft − o]` and `[gridRight + o, gridRight + o + L]`.
- **Above the top row / below the bottom row**, at each column edge x: a vertical tick of length L, **only if** `gridTop ≥ margin + o + L` (same for the bottom).

  - `testCounts`: Mini 3×3 = 9, unrotated; Square 2×3 = 6, unrotated; Wide 4, `rotated == true`; Polaroid 2×2 = 4.

  - `testTicksNeverTouchPrints`: for every format, no tick intersects any slot rect inset by −0.5 mm (expanded).
  - `testMiniHasNoTicksAboveOrBelowGrid`: all Mini tick y values lie within [6.7, 272.7]. `testPolaroidHasOuterTicks`: some tick has maxY < first slot minY.

### Task 3: Crop, image decode, rotation

**Files:** `Sources/FauxFilmKit/Crop.swift`, `Sources/FauxFilmKit/ImageIO+Ops.swift`, tests `CropTests.swift`, `ImageDecodeTests.swift`

**Interfaces — Produces:**
- `public struct Crop: Equatable, Sendable, Codable { var zoom: Double = 1 /* clamped 1...8 */; var center = CGPoint(x: 0.5, y: 0.5) /* unit coords of the rotated image */; var quarterTurns = 0 /* 0...3 clockwise */; func sourceRect(imageSize: CGSize, targetAspect: Double) -> CGRect; func clamped(imageSize: CGSize, targetAspect: Double) -> Crop }`. `imageSize` is the size **after** rotation. `sourceRect` is in pixels, y down. Base rect = the largest `targetAspect` rect inside the image, divided by zoom, centred at `center·size`, with its origin clamped to `[0, size − rectSize]`. `clamped` rewrites `center` to the clamped rect's centre.
- `public enum ImageDecoder { static func decode(data: Data, maxPixel: Int = 4096) -> CGImage?; static func decode(url: URL, maxPixel: Int = 4096) -> CGImage? }`. Uses `CGImageSourceCreateThumbnailAtIndex` with `FromImageAlways`, `WithTransform: true`, and `ThumbnailMaxPixelSize`.
- `public enum ImageOps { static func rotated(_ image: CGImage, quarterTurns: Int) -> CGImage }`

### Task 4: Looks and print rendering

**Files:** `Sources/FauxFilmKit/Looks.swift`, `Sources/FauxFilmKit/PrintRenderer.swift`, tests `LooksTests.swift`, `PrintRendererTests.swift`

**Interfaces — Consumes:** Tasks 1–3. **Produces:**
- `public enum FilmLook: String, CaseIterable, Codable, Sendable, Identifiable { case none, instant, faded; var displayName /* "None", "Instant", "Faded" */ }`
- `public enum LookProcessor { static func apply(_ look: FilmLook, printBrightness: Double, to image: CGImage) -> CGImage }`. `printBrightness` is in EV (`CIExposureAdjust`), range −1...1. Use one shared `CIContext`, working in sRGB. Recipes are the builder's call, but keep them subtle: Instant = slight black lift, warmth, a touch of vignette; Faded = stronger lift, lower contrast, warmer.
- `public struct RenderOptions: Sendable, Equatable { var printBrightness = 0.25; var paperTexture = false; var cornerGuides = true; var dpi = 300.0 }`
- `public enum FrameStyle { static let borderColor /* #F6F4EE sRGB */; static let guideColor /* grey 0.78 */; static let hairline: CGFloat = 0.25 /* pt */ }`
- `public struct PrintItem: Identifiable, Sendable { id: UUID; image: CGImage /* upright, decoded */; format: FilmFormat; crop: Crop; look: FilmLook; copies: Int }`
- `public enum PrintRenderer`:
  - `static func renderPicture(_ item: PrintItem, options: RenderOptions) -> CGImage`: rotate → crop via `sourceRect` → draw onto an **opaque white** canvas of `round(pictureW/25.4·dpi) × round(pictureH/25.4·dpi)` px → apply the look.
  - `static func drawCard(_ item: PrintItem, picture: CGImage, in ctx: CGContext, cardRectPt: CGRect, rotated: Bool, options: RenderOptions)`: `ctx` is in PDF points, y up. Fill the card as a rounded rect (`cornerRadius`) in the border colour, clip and draw the picture into `pictureRect` (with `windowCornerRadius`), add optional texture (faint noise, border only), then corner guides: a quarter-circle hairline of radius `cornerRadius` inset at each outer corner, when `cornerGuides` is on. **The card's own outer edge is not stroked.** When `rotated`, turn the card 90° clockwise inside `cardRectPt`.
  - `static func cardImage(_ item: PrintItem, options: RenderOptions, pixelsPerMM: Double) -> CGImage` for on-screen previews (uses `drawCard`).

  - `testPictureSizeMini300dpi`: 543 × 732 px.

### Task 8: Printing, export, size test

**Interfaces — Consumes:** `Session.pages(maxRows:)`, `SheetLayout.isInside`, `PDFComposer`.

- `@MainActor enum PrintController { static func print(session: Session, options: RenderOptions, window: NSWindow?); static func exportPDF(session:options:); static func printSizeTest(window:) }`
- Print flow:
  1. Set up `NSPrintInfo` with paper size 612×792, all margins 0, `scalingFactor = 1`, and horizontal/vertical pagination `.clip`.
  2. Convert `imageablePageBounds` (points, y up) to mm (y down).
  3. Check every layout with `isInside`. If a page fails, show an alert: "Your printer can't print this close to the edge. Print [n] per sheet instead?" Choosing yes rebuilds with `maxRows[format] = rows − 1`, never scaling.
  4. Build the PDF, then call `PDFDocument.printOperation(for:scalingMode: .pageScaleNone, autoRotate: false)` and `runModal`.
- First print only (`@AppStorage("didShowSizeTestHint")`): before printing, show an alert suggesting **File ▸ Print Size Test** first.
- Export: `NSSavePanel`, default file name `Faux Film Sheets.pdf`.
- Menu: File ▸ Print… (⌘P), Export PDF… (⇧⌘E), Print Size Test.
